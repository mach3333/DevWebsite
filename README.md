## Features

This portfolio is guided by a UI/UX-first approach, prioritizing clarity, accessibility, and intentional visual hierarchy. The interface is designed to feel intuitive and responsive across devices, with subtle motion used to support interaction rather than distract from content. 
Interactive elements and animations are integrated to reinforce user feedback and improve navigational flow, while visual assets from previous projects are used to create a more cohesive and engaging experience.

- Responsive layout
- Interactive UI
- Project showcase
